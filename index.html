Install in three steps 📲

Check the release notes, then download the build you want to try.

  1. 1

    Grab the latest release

    Open the GitHub release page, expand Assets, and select the APK file.

  2. 2

    Open your download

    Tap the APK. If Android asks, allow this browser or file manager to install unknown apps.

  3. 3

    Install and open

    Follow Android's prompts and review any security alerts. Keep Play Protect on. You can revoke the install permission afterward.

Good to know

Where do I download VXPlayer?

The download buttons open the latest GitHub release. Look under Assets for the APK and read the release notes.

Are the phone screens real?

The phones and the previews under "A look inside VXPlayer" are interactive illustrations of the interface, not screenshots of the app.

Will every video website work?

Some sites restrict embedded playback or use DRM. Direct media files and compatible streams work best, and support depends on the source and release.

How do I get updates?

Return to the same GitHub release page, check the latest notes, and install the update from the same publisher.
